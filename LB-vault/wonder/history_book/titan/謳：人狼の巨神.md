# Chapter 1
恐怖の章
## Page 1-1
人の感情で最も古いものは
恐怖だと聞く。
闇を、獣を、
隣人の心変わりを恐れて、
人は生きてきた。
「私は、人を生かすための力が
人を滅ぼすのを見た」
恐怖とは、脅威から遠ざかり
生存率を上げるための感情。
## Page 1-2
村をあげての盛大な祝宴が催された。
ありあまるほど酒と料理が振る舞われ、
飼い犬たちさえご馳走にありついた。 隣町で一番の大商人の息子のもとに
村長の娘が嫁ぐことになった。
大商人の息子は、偏屈で変わり者だったが
美しい娘はそんな彼を愛した。
新郎は全刺繍の礼服に狩りの獲物である
狼の毛皮を誇らしげに身につけ、
花嫁は亡き母のドレスの上に、
お気に入りの赤い肩かけをまとった。
## Page 1-3
宴席の中心で喜びに顔を輝かせるふたりに、
村人たちは暖かな祝いの言葉を贈った。
村人たちの喜びようには理由があった。
新郎はこの村で新婦とともに
暮らすことを望んでいる。
村はずれに大きな屋敷が建てられ、
その工事で村中が潤った。
これからも大商人のカネが流れ込み
村は栄えるだろう。
## Page 1-4
皆が喜びに沸く中で、
占い師だけが眉をひそめていた。
占いで凶相が出たというのだ。
しかし、欲に目がくらんだ村人は、
誰も占い師の言葉に
耳を貸そうとはしなかった。
祝宴は真夜中まで続き、
その翌日
## Page 1-5
村の広場で、
八つ裂きにあった占い師が
見つかった。
「村に、 人狼が
紛れ込んでいる」
瀕死の占い師は、
そう言い残して死んだ。
## Page 1-6
人狼とは、人と同じ姿をしながら、
人を狩り、喰らう、人の敵である。
見分ける手段は無い
人狼を滅ぼさなければ、
村は喰い尽くされる。
## Page 1-7
よそ者である新郎がまず疑われた。
彼を殺すのは簡単だ。
だが、 万が一間違いであれば
約束された村の繁栄は無かったことになる。 新郎は、自ら監禁されることを申し出た。
彼が牢に囚われている間に
人死にがでれば彼は人狼ではない。
逆に、これ以上人死にが出なければ、
処刑されても良いと、新郎は言った。
村人は彼の勇気を称え、
若い花嫁は悲嘆に暮れた。
## Page 1-8
狼の遠吠えと共に、夜がやってきた。
『私は愛する者を
守らなければならない』

# Chapter 2
狂乱の章
## Page 2-1
夜が明け次の犠牲者が見つかった。
水車小屋の守り番をしていた男だ。
無残にも喉笛が食いちぎられていた。
よそ者である新郎の疑いは晴れたが、
村人たちは狂乱状態となった。
村の門は固く閉ざされ、外からは何人も
入り込む事はできない。
人狼は、村人の中にいる。
素知らぬ顔をして、村人のひとりとして
生活を共にしてきたのだ。
## Page 2-2
逃げだした者は、人狼の疑いをかけられ
動けなくなるまで殴られた。
隣街へ兵士を
呼びに行こうとした者もいたが
殴られた村人を見て思いとどまった
村を離れれば、
「悪口ばかり言っているのは
お前が人狼だからだ」
同じ目にあうのは明らかだ。
次に、村の嫌われ者が、
やり玉にあがった。
「違うというなら証明して見せろ!」
## Page 2-3
証明などできるはずがない。
嫌われ者は村人に吊し上げられた。
## Page 2-4
「あいつに違いない。
夜に出歩く影をみたぞ」
「うちの鶏を盗んだあいつが人狼だ」
「旦那に色目を使っている女がいる」
「あんなろくでなしが小金を
持っているのはおかしい」
『私は、恐怖が村を支配し、
村人同士が凄惨な
殺し合いを始めるのを見た」
## Page 2-5
村長ですら、村人につきあげられ、
殺されてしまった。
村人は誰かを吊すたびに、人狼は死んだ!
と浮かれ大騒ぎをしたが、
翌朝になると新たな犠牲者が
出ているのを見て絶望した。
## Page 2-6
「やはり、よそ者である新郎が怪しい」
「お前がきたせいで、人狼があらわれた」
「ならば、 花嫁もだ。
お前が人狼を呼び込んだのだろう?」
## Page 2-7
新郎と新婦は村の広場に縛り上げられた。
人狼さえ現れなければ、
婚礼を行うはずだった広場だ。
ふたりの足下に焚き木が積まれた。
燃えさかる松明を持った村人たちが、
ふたりを取り囲んでいた。

# Chapter 3
微睡の章
## Page 3-1
高らかに喇叭が鳴り響き、
騎兵が姿をあらわした。
大商人の馬車隊を先導する護衛だ。
騎兵は村の広場を見て目を丸くした
村人たちの屍がいくつも吊されている。
その上、主人の息子と、 その花嫁が
火あぶりにされようとしているではないか。
## Page 3-2
「助けてくれ!」
新郎が叫ぶ。
「騙されるな! そいつは人狼だ!」
村人が騎兵を説得しようとする。
騎兵は新郎の味方であった
激昂した大商人の命令により、
騎兵は一人残らず村人の首をはねた。
## Page 3-3
呆然とする新婦の足下に
「私」はすりよる。
彼女はやさしく私の毛並みを
なでてくれた。
## Page 3-4
「私」と彼女が出会ったのは、
森の奥の水場だった。
間抜けにも猟師の罠を踏んでしまい、
動げなくなっていたときの事だ。
私の前に彼女があらわれた。
目が覚めるような赤い布を
首に巻いていたのをよく覚えている
彼女は弱っていた私に肉を与え、
おかげで私は命拾いをした。
彼女が私の命の恩人だ。
## Page 3-5
私は彼女のそばに仕える事を決めた。
彼女を守ることが、私の使命。
彼女には幸せになって欲しかった。
だから、
あの占い師を黙らせた。
それがこんな騒ぎに
発展するとは思わなかった。
## Page 3-6
私の飼い主は夫と一緒に隣街で
暮らすことになった。
忠実な飼い犬である私も、
彼女に従うことになった。
彼女のそばにいられることを
喜びながらも、
二つだけ気に掛かることがあった。
## Page 3-7
私が殺したのは、あの占い師だけだ。
「水車小屋の守り番や、
他の村人たちは
誰が殺ったんだろう?」
## Page 3-8
それを考えていると、
彼女が食事を持ってきてくれた。
いつもの赤い布をまとった彼女は美しい
食事は久しぶりの生肉だ。
血のしたたる肉に思い切りかぶりつくと、
くだらない疑問は薄れていった。
Fin.
