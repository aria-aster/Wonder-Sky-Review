# 本文
巨神と誓女で、名前に《》がついているキャラクター達が居ます。
このキャラクター達は、「誰かの物語を継いでいる」ではないかと思っています。

## 炎の騎士
「炎の騎士」に関係する名前について書き出します。
・セラフ
	巨神と誓女のセラフ（本当の名前：《炎の騎士》シャラト・アズリア）
	「魔術の巨神」でセラフとして登場
・エヴァ
	巨神と誓女のエヴァ（本当の名前：《炎の騎士》シャラト・アズリア）
	「旋塔の巨神」でウロボロスと対峙した人物
・シャラト・アズリア
	「旋塔の巨神」でウロボロスと対峙した人物
	氷の魔女「立ち上がれ、炎の騎士 シャラト・アズリア！」
	オリフラムの謳の冒頭でアスタルと会話していた人物、アスタルに「私の騎士」とも呼ばれている。
・アッシュ
	巨神と誓女のアッシュ（本当の名前：《四神将》アシュレイ・フルークリッター）
	「心眼の巨神」でサイレンと対峙し、クソフクロウが混沌に汚染されていると言った人物。
	アスタル「——大丈夫よ、 私の騎士が来てくれるから」　（※シルエットのみ）

・全員がリーパーを持っていて、神の騎士の契約をしている。（と思われる）
・セラフは「ノイアに仕える炎の騎士」
・アスタルは「ノイアの器」となった人物
・シャラト・アズリアはウロボロス戦で一度灰（ash）になっている。

**「時系列を無視すれば」**、「セラフ」「エヴァ」「シャラト・アズリア」「アッシュ」
炎の騎士に関係する４つの名前は**全て同一人物**と思われます。

「時系列を無視すれば」と付けた理由：
　「シャラト・アズリア」がリーパーと契約して炎（神）の騎士になったのは、
　「ハイランド女王国とヴァルマン魔法帝国」の時代で、
　「セラフ」の登場したのはそれより前の「古代魔法王国」の時代だからです。
　「魔術の巨神」で「セラフ（ノイアの騎士）」は「どれだけの時を渡ったことか！」と発言しています。
　万書殿（パンベリウム）は過去から未来の全ての書が存在するので、
　過去の物語世界にも干渉できうるのかもしれません。
